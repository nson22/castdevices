O app agora se chama **CastDevices** (antes SCRCPY UI). As funcionalidades são as mesmas, para Windows, macOS e Linux.

## Download

Não precisa instalar Python nem o Android platform-tools: o **adb oficial já vem junto**, na mesma versão usada pelo scrcpy (platform-tools 37.0.0). O device precisa estar com a **depuração USB** ativada.

| Sistema | Arquivo | Como usar |
|---|---|---|
| Windows | `castdevices-v0.0.5-alpha-win64.zip` | Extraia e abra `castdevices.exe` |
| macOS (Apple Silicon) | `castdevices-v0.0.5-alpha-macos-arm64.dmg` | Abra o `.dmg` e arraste o **CastDevices** para Aplicativos |
| Linux (x86_64) | `castdevices-v0.0.5-alpha-linux-x86_64.tar.gz` | Extraia e rode `./castdevices`, ou `./install.sh` para criar o atalho no menu |

**macOS:** o app ainda não é assinado pela Apple. Na primeira vez que abrir, clique com o botão direito no app e escolha **Abrir**. Também funciona rodar `xattr -dr com.apple.quarantine "/Applications/CastDevices.app"` no Terminal.

**Linux:** precisa de uma distro com glibc 2.35 ou mais nova (Ubuntu 22.04+, Debian 12+, Fedora 36+).

Cada arquivo tem um `.sha256` ao lado para conferir o download.

## Novidades
- **Novo nome:** CastDevices.
- **Licença Apache 2.0:** os pacotes trazem as licenças e os avisos dos componentes de terceiros. A pasta de licenças pode ser aberta em **Configurações → Sobre**.
- **Pacotes menores e só com o necessário:** os módulos do Qt licenciados apenas como GPL, que o app não usa, saíram do pacote.

## Mudanças que você pode notar
- **Arquivos e atalhos:** o executável, o app do macOS e o atalho do Linux mudaram de nome. Se você usou o `install.sh` de uma versão anterior no Linux, rode `./install.sh --remove` dela para tirar o atalho antigo.
- **Pastas e nomes padrão:** novos screenshots e gravações vão para a pasta `CastDevices` (em Imagens e Vídeos) e o nome dos arquivos começa com `castdevices_`. Pastas escolhidas por você nas Configurações não mudam, e as outras configurações também são mantidas.

## Limitações conhecidas
- O uso com device real foi validado no Windows. No macOS e no Linux, o CI confere que o app abre e que o adb embutido funciona.
- O pacote de macOS é só para Apple Silicon (M1 ou mais novo).
