Primeira versão do **SCRCPY UI** para **Windows, macOS e Linux**.

## Download

Não precisa instalar Python nem o Android platform-tools: o **adb oficial já vem junto**, na mesma versão usada pelo scrcpy (platform-tools 37.0.0). O device precisa estar com a **depuração USB** ativada.

| Sistema | Arquivo | Como usar |
|---|---|---|
| Windows | `scrcpy-ui-v0.0.4-alpha-win64.zip` | Extraia e abra `scrcpy-ui.exe` |
| macOS (Apple Silicon) | `scrcpy-ui-v0.0.4-alpha-macos-arm64.dmg` | Abra o `.dmg` e arraste o **SCRCPY UI** para Aplicativos |
| Linux (x86_64) | `scrcpy-ui-v0.0.4-alpha-linux-x86_64.tar.gz` | Extraia e rode `./scrcpy-ui`, ou `./install.sh` para criar o atalho no menu |

**macOS:** o app ainda não é assinado pela Apple. Na primeira vez que abrir, clique com o botão direito no app e escolha **Abrir**. Também funciona rodar `xattr -dr com.apple.quarantine "/Applications/SCRCPY UI.app"` no Terminal.

**Linux:** precisa de uma distro com glibc 2.35 ou mais nova (Ubuntu 22.04+, Debian 12+, Fedora 36+). Para acessar o device via USB sem root, pode ser preciso configurar as regras `udev` do Android. No Debian/Ubuntu, elas vêm no pacote `android-sdk-platform-tools-common`.

Cada arquivo tem um `.sha256` ao lado para conferir o download.

## Novidades
- **Novo nome e ícone:** SCRCPY UI.
- **macOS e Linux:** pacotes novos, gerados automaticamente pelo GitHub Actions a cada release e testados antes de publicar.
- **adb embutido:** a versão fixada do platform-tools oficial vem nos três sistemas, como no scrcpy.

Tudo da versão anterior continua: espelhamento com áudio, controle por mouse e teclado, gravação, screenshot, clipboard, instalação e desinstalação de apps, e a árvore de hierarquia da tela com atualização automática.

## Limitações conhecidas
- O uso com device real foi validado no Windows. No macOS e no Linux, o CI confere que o app abre e que o adb embutido funciona, mas ainda não houve teste com device.
- O pacote de macOS é só para Apple Silicon (M1 ou mais novo).
- AV1 depende do device ter encoder de hardware e de o decoder estar disponível.
